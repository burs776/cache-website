01 / ABOUT THE IDEA BEHIND THE MEMORY

EVERYTHING
IS TEMPORARY.

The internet creates more memories than it can keep.

Memes appear, spread, and disappear. What feels unforgettable today can become invisible tomorrow. CACHE turns this endless cycle into a shared experiment.

Imagine a character with only 64 memory slots. Every new memory takes up space. The community decides which moments deserve to remain — and which ones become part of the forgotten internet.
